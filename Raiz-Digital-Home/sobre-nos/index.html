SOBRE O PROJETO "RAIZ DIGITAL"

Diante a necessidade de desenvolver um projeto
para o nosso projeto multidisciplinar (TCC),
percebemos a importância da tecnologia no curso de
Agronegócio como forma de facilitar a realização de
tarefas básicas. Foi então que surgiu o “Raiz Digital”,
um site com ferramentas que oferece
funções para auxiliar no controle
dos dias de irrigação, escaneamento (Scan)
para o acessar os códigos de resposta rápida (QR
Codes), entre outras funcionalidades.
